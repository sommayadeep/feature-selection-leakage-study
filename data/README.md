# Dataset access

The raw and processed leukemia dataset files are intentionally **not included**
in this repository. The exact file used by the experiments is a Stanford CASI
mirror whose data-use and redistribution terms remain unresolved.

The local raw file expected by `src/prepare_leukemia.py` is:

```text
data/raw/leukemia_big.csv
```

The processed file generated by that script is:

```text
data/processed/leukemia.csv
```

The Phase 9A provenance report records the verified source URL, file hashes,
the Golub et al. (1999) citation, and the unresolved licensing and feature
mapping issues:

- [`../reports/phase9a_dataset_provenance.md`](../reports/phase9a_dataset_provenance.md)
- Stanford CASI data page:
  <https://hastie.su.domains/CASI_files/DATA/leukemia.html>

Do not download, redistribute, or publish the data until the applicable
research-use and redistribution terms have been clarified. Authorized
researchers should place the source file at the path above, verify its
SHA-256 against the provenance report, and then run:

```bash
PYTHONPATH=src python src/prepare_leukemia.py
```
